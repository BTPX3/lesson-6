
# Порівняння ноутбуків

## Опис проєкту
Навчальний проєкт зі створення вебсторінки з таблицею порівняння характеристик трьох ноутбуків: MacBook Air, ASUS VivoBook та Lenovo IdeaPad.

Мета проєкту — закріпити навички роботи з HTML і CSS, навчитися створювати семантичні таблиці та правильно оформлювати вебсторінки.

## Використані технології
- HTML5 — структура вебсторінки.
- CSS3 — оформлення та адаптивність.
- WOFF2 — локальний вебшрифт Quicksand.
- @font-face — підключення локального шрифту.
- GitHub Pages — публікація проєкту.

## Виконані завдання
- Створено контентний контейнер з обмеженою максимальною шириною та центруванням.
- Підключено локальний WOFF2-шрифт із системним резервним шрифтом.
- Створено семантичну HTML-таблицю з caption, thead, tbody, th та td.
- Для заголовків таблиці використано атрибут scope.
- Налаштовано межі таблиці та чергування кольорів рядків.
- Застосовано базову нормалізацію CSS.

## Перевірка
Сторінку перевірено у браузері Firefox, Chrome.

У DevTools перевірено обчислені стилі основних елементів, зокрема шрифт, відступи, межі таблиці та властивість border-collapse.

Завантаження локального шрифту перевірено. Резервний системний шрифт передбачено у font-family.

Також перевірено відображення сторінки при зміні ширини вікна браузера.

Друге середовище для перевірки недоступне, тому кросбраузерне порівняння не проводилося.

## Підсумок
У результаті створено адаптивну вебсторінку з таблицею порівняння ноутбуків. Закріплено навички використання семантичної HTML-розмітки, CSS-стилізації, підключення локальних шрифтів та роботи з адаптивним контейнером.

Проєкт допоміг краще зрозуміти принципи оформлення таблиць і перевірки стилів за допомогою DevTools.
